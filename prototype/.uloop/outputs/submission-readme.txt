ELEMENT SHIFT — 提出用 Windows 64bit ビルド
作成日: 2026年10月9日

起動方法
1. ZIPをすべて展開してください。
2. ElementShift.exeを起動してください。
3. タイトル画面の ENTER THE ARENA からゲームを開始します。
※ exe・UnityPlayer.dll・ElementShift_Dataなど、同梱ファイルを同じフォルダーに置いてください。

ゲームの目的
敵を倒してボスを出現させ、ボスを撃破するとゲームクリアです。
ボスの死亡演出後、勝利モーションとリザルトが表示されます。

キーボード操作
WASD: 移動
矢印キー: 視点操作
J: 通常攻撃
K: 強攻撃
Space: 回避
L: 必殺技（ゲージMAX時）
Q / E: 属性切り替え
Esc: 設定ポップアップの開閉
R: リザルト／ゲームオーバー画面からリスタート

ゲームパッド操作（Xbox / PlayStation）
左スティック: 移動
右スティック: 視点操作
X / □: 通常攻撃
Y / △: 強攻撃
A / ×: 回避
B / ○: 必殺技
LB・RB / L1・R1: 属性切り替え
Menu / Options: 設定ポップアップの開閉
設定画面: 方向入力で項目を選択、左右でスライダー調整、A / ×で決定、B / ○で閉じる

設定
BGM・効果音・ボイス音量、解像度、全画面／ウィンドウ、画質、
一人称／三人称、視点感度、振動ON／OFFを変更できます。
初期視点は一人称です。設定の CAMERA から三人称へ変更できます。
設定値は保存されます。ボイス音源は現在未登録です。
設定画面内の RESTART BATTLE からもリスタートできます。

終了
ウィンドウを閉じるか、Alt+F4を押してください。
