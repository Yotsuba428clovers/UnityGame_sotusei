# 完全リセット型ローグライト：実装内容

## 地面と空

地面はAssets/materials/textures/flat_tex.pngを使用。300m四方のPlaneに37.5回ずつ繰り返し、約8mを1タイルとしている。QuickSetupのgroundTileWorldSizeで大きさ、groundMaterialでマテリアルを差し替えられる。
テクスチャはRepeat、ミップマップあり、Trilinear、異方性8。地面マテリアルはAssets/Resources/Environment/GrassStoneGround.mat。旧環境の仮床タイルと床目地を外し、地面の模様が隠れないようにした。
空はAssets/Resources/Environment/DaylightSky.matとAssets/Shaders/SoftDaySky.shaderで描画する。青空のグラデーション、緩やかに流れる柔らかな雲、太陽の光を追加。暖かい日光・空からの環境光・淡い青の遠景霧に調整した。空の色と雲量はマテリアルから調整可能。
地面・空のランタイムマテリアルは終了時に破棄し、環境設定を復元する。Unityで地面テクスチャ、37.5×37.5タイリング、スカイボックス適用と実画面を確認。コンパイル・実行時エラーなし。

## 実装範囲

### 敵の固有属性廃止と状態異常表示

EnemyからweakElement、weakMultiplier、resistMultiplierを削除。スポーン時の属性抽選、頭上の属性マーカー、弱点ダメージ倍率/耐性倍率、弱点用ダメージ数字の強調を撤去した。ボスのノックバック軽減と属性攻撃による状態異常は維持。
EnemyStatusVisualがモデルの全Renderer・全マテリアルスロットへ、強い乗算色とスクリーン補正、控えめな発光を適用する。Unity Toon Shaderでは基本色に加えて1段目/2段目の影色とEmissiveを変更し、URP Litにも対応。元の共有マテリアルアセットは変更せず、敵ごとのインスタンスのみを扱う。

| 状態 | 表示 |
| --- | --- |
| 炎上 | 赤 |
| 冷却・凍結 | 青 |
| 感電 | 黄 |
| 風の吹き飛ばし | 緑 |
| ボスのブレイク | 氷とは区別した灰青 |

頭上に現在有効な状態名を並べ、日本語/英語設定にも対応。複数状態が重なった場合は最新の有効な攻撃属性の色を優先し、凍結中は青を優先する。終了した状態は表示から消え、全状態終了で元の色・発光色・発光テクスチャ・キーワードへ復元する。
攻撃予兆は床の予告エフェクトで示し、敵全体を赤くする旧予兆表示は撤去した。被弾の白フラッシュも属性色が消えない程度に弱めた。
EnemyStatusVisualのmultiplyStrength、screenStrength、emissionStrengthで濃さを調整できる。
Unityで4属性の直接ダメージ統一、実モデルでの4色、複数状態名、全色スロットの復元を検証。2サブメッシュ/2マテリアルのテストでも両スロットが染まり、暗い素材が視認でき、共有アセットを変更せず発光設定が復元されることを確認。最終コンパイルはエラー/警告0、実行時エラー0。

共有チャットの7システムを既存プロジェクトへ接続した。

| システム | 実装 |
| --- | --- |
| RunManager | シーン単位のラン開始・死亡・クリア・再挑戦。GameManagerから自動生成 |
| UpgradeManager | 戦闘報酬の3択抽選、レア度重み、同じ候補の重複防止、取得上限 |
| PlayerBuild | ラン内強化の保持、基礎性能補正、16種の追加効果 |
| EnemyWaveManager | 有限の4ウェーブ、各ウェーブ後に報酬、最後にボス |
| RewardUI | 3択・死亡・クリア結果、再挑戦・タイトル移動、自己ベスト表示 |
| RunResultManager | 成否・時間・撃破数・最大コンボの一度だけの記録 |
| SaveManager | ラン数、クリア数、最高撃破、最大コンボ、最短クリア時間、前回結果 |

GameManagerは既存HUD・勝利演出向けの窓口として維持。既存EnemySpawnerのPrefabと仮モデル生成処理を利用し、従来の無限出現処理を停止してウェーブ管理に一本化した。
新規コンポーネントのシーン配置は不要。QuickSetupで生成されるGameSystemsから自動接続する。

## ゲームの流れ

タイトル → ラン開始 → ウェーブ1〜4 → 各ウェーブの敵を全滅 → 強化を1つ取得 → 最終ボス → 勝利演出 → リザルト。
途中で死亡した場合もリザルトへ進み、再挑戦できる。
初期出現数は既存EnemySpawner.startingEnemies、次のウェーブごとに4体追加。maxAlive、batchSize、spawnIntervalも既存設定を利用。
ウェーブ数はEnemyWaveManager.normalWaves（初期値4）。

報酬選択中は時間を停止する。移動・攻撃・敵AIをブロックし、ヒットストップ処理による時間停止の上書きも防止。
設定画面は報酬画面より手前に表示し、設定表示中は強化を選べない。
クリア時は既存の勝利演出が終了してから結果画面を表示。旧結果パネルとの重複表示を抑止。
計測時間はTime.deltaTimeによる戦闘中の時間で、設定・報酬選択の停止時間は含めない。

## 16種類の強化

| 強化 | 現在の効果 |
| --- | --- |
| 追撃の刃 | 4段目に半径5m、通常威力の60%の範囲衝撃波 |
| 回避の達人 | ジャスト回避で最大HPの3%回復 |
| 反撃の構え | ジャスト回避後の次の攻撃を1.5倍 |
| 破砕撃 | 強攻撃のボスブレイク値30を39へ強化 |
| 連撃の極意 | 有効なコンボ10Hitごとに攻撃力+3%、上限30% |
| 炎刃 | 通常攻撃に20%の炎属性追加ダメージ |
| 爆炎 | 炎上中の敵の撃破時、半径3mへ通常威力75%の炎爆発 |
| 疾風 | 通常攻撃速度1.15倍、既存の風バフと乗算 |
| 風刃 | フィニッシュ時、前方中心の半径4mへ通常威力50%の風斬撃 |
| 氷結刃 | 同じ敵への通常攻撃3Hitで2秒凍結、ボスは既存の時間短縮あり |
| 氷砕 | 凍結中の敵への強攻撃に50%の氷属性追加ダメージ |
| 雷撃 | 通常攻撃の命中ごとに20%で近傍最大3体へ40%威力の雷撃 |
| 雷迅 | ジャスト回避時、半径5mへ通常攻撃相当の雷撃 |
| 剣の加護 | 初期最大HPの20%を加算、増加分を回復、最大5回 |
| 魔力循環 | 命中時ゲージ獲得量を初期値の20%加算、最大5回 |
| 鋭利な刃 | 通常・強攻撃力を初期値の10%加算、最大5回 |

追加ダメージはEnemy.TakeHitを経由して状態異常を付与する。敵の固有属性と弱点・耐性倍率は廃止し、同じ威力の直接攻撃は属性によらず同じダメージになる。
追加攻撃からさらに通常攻撃の強化判定を発火させない構成。
ジャスト回避は回避開始後0.12秒内の被弾判定で成立。同じ回避では1回のみ報酬が発生し、残りの回避無敵時間とは区別する。
成功時は0.3秒間、速度35%から滑らかに通常速度へ戻すスローモーションを再生。水色の足元リング、白い縦リング、薄い画面フラッシュと軽いカメラ演出を追加した。CombatPresentationのjustDodgeDuration、justDodgeTimeScale、justDodgeColorで調整可能。従来の0.08秒ヒットストップは置き換えた。Unity上でスロー発動、2種リング生成、同じ回避での重複防止、通常速度への復帰を検証済み。
ボスはブレイク値100。強攻撃で削り切ると約3秒間ダウンする。氷の凍結とブレイクは別状態として扱う。

## 強化アセットの編集

### 属性相乗効果

各属性の強化を1つ以上取得すると、その属性を獲得したものとして判定する。炎＝炎刃/爆炎、氷＝氷結刃/氷砕、風＝疾風/風刃、雷＝雷撃/雷迅。装備中の属性を切り替えただけでは発動しない。複数の組み合わせを同時に有効にでき、HUDに発動中の組み合わせを表示する。

| 組み合わせ | 初期効果 |
| --- | --- |
| 炎×風 | 炎属性の直接攻撃・範囲追加攻撃・爆発の判定半径を1.3倍 |
| 炎×雷 | 炎の必殺技と追加爆発から最大3体に40%威力の雷撃 |
| 炎×氷 | 攻撃前から凍結している敵への命中で40%威力の追加爆発。対象自身と周囲に命中し、同じ対象には0.5秒間隔 |
| 氷×雷 | 凍結中の敵への雷属性ダメージを1.5倍。直接攻撃・連鎖・回避雷撃に適用 |
| 氷×風 | 攻撃速度が1倍を超える間、通常攻撃の凍結蓄積が2倍（3蓄積に通常2Hit）。氷結刃が必要 |
| 風×雷 | 雷撃強化の抽選率を20%から35%へ。雷撃強化が必要 |

追加爆発からの死亡でさらに爆発を再帰発生させない。相乗効果、対象別の蓄積・再発動制限はラン内データであり、再挑戦時に消去する。
Unity上で6効果、炎の拡大範囲への命中、爆発の追加雷ダメージ、凍結敵自身への爆発と再発動制限、雷ダメージ倍率、凍結蓄積加速、雷撃確率、発動一覧とリセットを検証した。

Assets/Resources/RogueliteUpgradesに16個のUpgradeDataアセットを配置済み。
Inspectorで名前、説明、レア度、最大取得回数を変更できる。効果の倍率・範囲は現在PlayerBuildのコードに定義している。
Create → Roguelite → Upgradeから追加可能。effectは既存16種類の効果識別子。
同じeffectのアセットを複数作らないこと。既存UpgradeManagerのcatalogに明示指定した場合は、その配列を優先する。
初期のレア度重みはCommon 60 / Rare 30 / Epic 10。候補ごとの抽選時に残っているレア度内の件数で割る。上限到達と重複除外により実際の出現比率は変わる。
全候補が上限到達した場合は報酬をスキップして進む。

## 操作

### 日本語・英語の切り替えとタイトル設定

初期表示は日本語。タイトルに「設定」ボタンを追加し、戦闘中と同じ音量・画面・操作・言語設定を開ける。
「設定 → 言語」を押すと日本語 / Englishを即時切り替え。ElementShift.Settings.Languageに保存し、シーン移動・再起動後も引き継ぐ。タイトルでは戦闘再開始ボタンを表示しない。
タイトル・操作説明・設定項目・戦闘HUD・報酬強化名/説明・結果表示を切り替える。タイトルの操作説明は現在のPS5配置と一致させ、報酬選択・再挑戦の操作も記載した。
タイトルで設定したカメラ視点は次の戦闘にも適用する。Esc / OPTIONSで設定を開閉できる。操作説明中のEscは説明のみを閉じ、設定と同時に表示しない。
UiLanguageに翻訳、LocalizedLabelに元文字列と表示の管理をまとめた。既存のシーン内テキストと実行時生成ラベルへ接続し、日本語フォントと長文の自動縮小を適用。翻訳元は保持し、言語切り替えを繰り返しても文言や設定値を失わない。
Unityで日本語/英語のタイトルと設定・操作説明を画像確認。タイトルの設定ボタンと設定内の言語ボタンをクリック経路で検証し、数値保持・シーン間の保存・英語強化名/説明・設定と報酬の入れ子の時間停止・Escの動作を確認した。

PC戦闘操作：WASD移動、マウス視点、F通常攻撃、G強攻撃、Space回避、Z ULT、Q/E属性切替。旧J/K/Lと矢印キーの視点操作は外した。ゲームパッドは既存の右スティック視点、西＝通常、北＝強攻撃、南＝回避、東＝ULTを維持。
マウスはフレームごとの移動量として扱い、スティックの角速度入力と別に計算する。感度は設定のカメラ感度に連動し、初期値140では1pxあたり0.21度。戦闘中はカーソルを中央固定・非表示とし、設定・報酬・リザルト・フォーカス喪失時は解除。再固定直後の2フレームはマウス移動を無視して視点飛びを防止する。設定と報酬の表示中はカメラを動かさない。
タイトルの日本語/英語操作説明と戦闘HUDを新しい割り当てに更新した。Unityの実入力でFの通常攻撃、Gの強攻撃、攻撃可能な状態でZのULTとゲージ消費、120pxのマウス移動で25.2度の視点移動を確認。設定中のカーソル解除・カメラ停止・閉じた後の視点飛び防止、報酬中のカーソル解除、タイトルとHUDの表記も確認済み。
報酬画面：左右矢印・十字キーで選び、Enter・南ボタン（DualSenseの×）で決定。1/2/3キー、マウスクリックでも選択可能。
リザルト：再挑戦・タイトルボタン。同じ左右選択と決定操作が利用可能。Rキーの再挑戦も維持。

## 完全リセットと保存

再挑戦は戦闘シーンを再読み込みし、敵・ボス進行・タイマー・コンボ・VFX・回避状態・一時バフも再生成する。
PlayerBuildはシーンで設定された初期性能を捕捉し、ラン開始時に初期HP、ゲージ0、炎属性、強化なしへ戻す。
戦績保存キーはPrototype.Roguelite.Records.v1。能力値や強化は保存せず、戦績を攻略性能へ反映しない。既存設定キーは変更しない。

## 確認結果

Unity 2022.3.0f1の実コンパイル：エラー0、警告0。
Unityプレイモードで以下を検証：

- 初期ビルド、16種類のカタログ、3択候補の重複防止、選択時のウェーブ移行。
- HP・攻撃力・攻撃速度補正、凍結蓄積、反撃倍率。
- 報酬選択時の時間停止、保存アセット16個の読み込み。
- 死亡 → 一度だけの戦績保存 → 再挑戦 → 強化と能力値のリセット。
- 最終ボス出現、ブレイク、撃破、勝利演出後の結果表示。
- リザルトの再挑戦ボタンをEventSystemのクリック経路で操作し、初期化を確認。
- 日本語の報酬・結果UIを画像で確認。最終時点でConsoleの実行時エラー0件。

テストではウェーブ残数や敵HPを実行時に操作して遷移を短縮している。通常プレイによる1ラン全体の所要時間、全16効果の組合せ、実機ゲームパッドの操作感、Windowsビルドは未検証。検証中の戦績は検証開始時の内容に復元した。

## 仕様書との境界

今回の実装範囲は共有チャットの7システムと16強化の接続。元仕様書にあるジャンプ、R3ロックオン、専用の空中コンボ、ルート分岐、弓AI、4属性必殺技の全面改修、近接攻撃権の制御は含まない。
既存の氷回復・雷ダッシュ強化・風バフ、一人称/三人称の切替設定を維持している。ダメージ、ブレイク、報酬頻度は初期値で、15〜20分のランと難易度に合わせる調整が必要。
